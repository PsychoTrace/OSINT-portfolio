# CTE - L'Enfer Numérique 2026

Write-up complet du CTF **Opération Vérité**, réalisé entre le 5 et le 12 juin 2026.

## Contexte de la mission

Investigation autour de **Mélanie Lefèvre**, victime d'une usurpation d'identité liée à une organisation criminelle spécialisée dans le vol de données personnelles (faux sites immobiliers, phishing, ingénierie sociale). L'enquête part de son entourage (colocataire Samir, contacts) pour remonter jusqu'au réseau criminel derrière les faits : **Fantasmas de Redes**.
